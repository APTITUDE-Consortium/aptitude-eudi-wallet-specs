# RFCs (Request for Comments)

This section contains the Request for Comments (RFCs) that define the technical profiles and specifications for the APTITUDE pilot.

!!! note "Recommended background reading"

    The [Generic Issuance Flow Specification](../wp2/generic-issuance-flow-specification.md) is a non-normative companion that walks the end-to-end APTITUDE credential issuance flow as a single sequence diagram and maps each step to the RFC section that governs it — read it first for the overall picture, then use the RFCs below for the normative detail.

| Document                                        | Description                                                                                      |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [RFC-01 Credential Issuance Profile](RFC001.md) | Defines the credential issuance flow and baseline specifications for APTITUDE pilots             |
| [RFC-02 Presentation Profile](RFC002.md)        | Defines the credential presentation and verification flow for APTITUDE pilots                    |
| [RFC-03 Trust Framework](RFC003.md)            | Test matrix for piloting and Interoperability Test Bed with the Trust Framework piloting requirements |
| [RFC-04 Revocation Profile](RFC004.md)          | Defines the profile for interoperable credential verification across APTITUDE pilots |
|                                                 |                                                                                                  |
