# Attestation catalogue

The catalogue holds one rulebook and one set of data schemas for each attestation type of the APTITUDE pilot. Its layout follows the catalogue of the WE BUILD consortium and the `rulebook-catalog` layout of [registry-cli](https://github.com/sirosfoundation/registry-cli), so the same tree renders on this site and feeds the [SIROS Credential Registry](https://registry.siros.org). [Structure of the catalogue](structure.md) describes the layout, the naming rules and the checks, and [Publishing in the registry](registry.md) describes the input for registry-cli.
