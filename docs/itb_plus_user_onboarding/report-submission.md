# Reporting Conformance Results

To demonstrate conformance to the relevant APTITUDE RFCs, participants should submit a successful conformance statement report to the APTITUDE project team.

## Submission Channels

The report may be submitted through one of the following channels:

- Email to the WP2 leads
- APTITUDE Slack support channel: `#itb-support`

## Required Information

When submitting the report, include the following:

- Organisation name
- Tested component role: Issuer, Verifier, Wallet Unit, or combination
- Targeted APTITUDE RFCs and profiles
- Date of test execution
- Attach the downloaded conformance statement report
- Relevant comments, limitations, or known issues
