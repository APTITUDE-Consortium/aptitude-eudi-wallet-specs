# Testing and Conformance Overview

This section explains how APTITUDE participants validate implementation readiness using ITB+ and how conformance evidence is submitted to WP2/T2.2.

Use the onboarding guide for end-to-end operational steps, screenshots, and report submission details.

- [ITB+ User Onboarding Guide](aptitude-itb-user-onboarding-manual.md)
- [Reporting Conformance Results](report-submission.md)

## Scope

The current ITB+ onboarding and conformance flow supports testing for:

- Wallet Unit
- Issuer
- Verifier

## Recommended Path

1. Request onboarding access and provide organisation and technical contact details.
2. Access ITB+ and open the APTITUDE conformance statements area.
3. Execute relevant test cases for the selected RFC profile and role.
4. Inspect logs and download conformance reports.
5. Submit successful conformance evidence to WP2/T2.2.
